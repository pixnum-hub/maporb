Navigation Map PWA
===================
Built from the uploaded navigation-map artwork.

Open index.html through HTTPS (or localhost) to install as a PWA.
Includes GPS, search, routing modes, nearby search, 12 map variations,
multi-point distance measurement, favorites/recent, themes, and emergency
location sharing.

The public map/geocoding/routing/Overpass services require internet access
and should be reviewed for production rate limits and usage policies.
